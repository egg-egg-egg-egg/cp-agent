# 2026 年 CSP-J 第二轮模拟赛（一）· 标程与解析

## 命题说明

这套题的考点与难度梯度按近五年（2021–2025）CSP-J 第二轮真题统计结果设计：

- **T1 送分题**：纯实现，字符串处理 + 排序，15–20 分钟应拿满分。
- **T2 基础题**：需要把一个"依次执行"的过程转化成可判定的模型（差分 + 二分答案），20–30 分钟。
- **T3 区分题**：需要识别"最少资源 = 最大重叠"这个模型，并处理大值域（不能开数组），30–45 分钟。
- **T4 压轴题**：动态规划建模 + 滑动窗口最小值优化，45–60 分钟。

四道题的主考点（字符串排序、差分、扫描线、线性 DP + 单调队列）**均未在近五年真题中作为主考点出现过**，避免与真题撞模型；同时全部落在入门级大纲范围内，不出现线段树、树形 DP、网络流等超纲内容。

## T1 图书编号

**考点**：字符串解析、排序、字典序
**难度档位**：送分题　**建议用时**：15–20 分钟

### 思路

对每个编号，把字母部分和数字部分切开：数字部分逐位累加成整数（这样前导零会被自然处理掉，`"0007"` 得到 $7$），字母部分保留原串用于字典序比较。然后按"数值升序 → 字母字典序升序"排序，输出原字符串。

复杂度 $O(n \log n)$。

### 标程

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Item {
    string letters;
    long long num;
    string raw;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    vector<Item> a(n);
    for (int i = 0; i < n; i++) {
        string s;
        cin >> s;
        int p = 0;
        string letters;
        while (p < (int)s.size() && s[p] >= 'A' && s[p] <= 'Z') {
            letters += s[p];
            p++;
        }
        long long num = 0;
        for (int j = p; j < (int)s.size(); j++) {
            num = num * 10 + (s[j] - '0');
        }
        a[i] = {letters, num, s};
    }

    sort(a.begin(), a.end(), [](const Item &x, const Item &y) {
        if (x.num != y.num) return x.num < y.num;
        return x.letters < y.letters;
    });

    for (const Item &it : a) cout << it.raw << '\n';
    return 0;
}
```

### 典型失分点

- 直接用字符串比较数字部分：`"10" < "9"` 在字典序下成立，但数值上 $10 > 9$。
- 忽略前导零：`"XYZ0007"` 的数值是 $7$，不是 $70000$ 也不是 $7$ 位数。
- 输出时输出了解析后的数字而不是原始编号字符串。
- 排序稳定性：数值相同时必须用字母部分比较，不能依赖输入顺序。

## T2 浇水

**考点**：差分、二分答案、单调性分析
**难度档位**：基础题　**建议用时**：20–30 分钟

### 思路

关键观察：**浇水次数越多，每盆花只会越高，不会变矮**。所以"是否达标"关于操作次数 $k$ 是单调的 —— 一旦第 $k$ 次之后达标，之后永远达标。这就是二分答案的信号。

判定函数 `check(k)`：只执行前 $k$ 次浇水，用差分数组 $O(n + k)$ 求出每盆花的高度，判断最大值是否 $\ge X$。答案就是最小的达标 $k$（$0 \le k \le m$）；若 `check(m)` 为假，输出 $-1$。

复杂度 $O((n + m)\log m)$。

### 标程

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    long long X;
    cin >> n >> m >> X;

    vector<long long> h(n + 1);
    for (int i = 1; i <= n; i++) cin >> h[i];

    vector<int> L(m + 1), R(m + 1);
    for (int j = 1; j <= m; j++) cin >> L[j] >> R[j];

    // 差分 + 二分答案：判断前 k 次浇水后是否存在高度 >= X 的花
    vector<long long> diff(n + 3, 0);
    auto check = [&](int k) -> bool {
        fill(diff.begin(), diff.end(), 0);
        for (int j = 1; j <= k; j++) {
            diff[L[j]] += 1;
            diff[R[j] + 1] -= 1;
        }
        long long add = 0;
        for (int i = 1; i <= n; i++) {
            add += diff[i];
            if (h[i] + add >= X) return true;
        }
        return false;
    };

    if (check(0)) {
        cout << 0 << '\n';
        return 0;
    }

    int lo = 1, hi = m, ans = -1;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        if (check(mid)) {
            ans = mid;
            hi = mid - 1;
        } else {
            lo = mid + 1;
        }
    }
    cout << ans << '\n';
    return 0;
}
```

### 典型失分点

- 忘记特判 $k = 0$（初始就有花达标，答案为 $0$）。
- 二分下界从 $1$ 开始、漏掉 $-1$ 的情况，或者二分初始区间写错导致死循环。
- 高度用 `int`：$h_i$ 可达 $10^9$，再加最多 $2\times10^5$，必须用 `long long`。
- 每次 `check` 都重新 `vector` 分配导致常数过大（本标程复用一个数组 + `fill`）。
- 部分分策略：$n, m \le 5000$ 时可以直接逐次模拟（每次 $O(n)$ 求最大值），能拿 60 分。

## T3 舞台

**考点**：扫描线、区间重叠、贪心（区间图着色）
**难度档位**：区分题　**建议用时**：30–45 分钟

### 思路

把"演出 + 清扫"打包看：第 $i$ 场演出实际占用的是闭区间 $[l_i,\ r_i + 1]$（多出来的 $1$ 个时刻用于清扫）。两台演出能共用舞台，当且仅当它们的占用区间不相交。

于是问题变成：**最少需要多少个资源，使得互相冲突的区间不共用**。对区间而言，答案恰好等于**同一时刻最多有多少个区间在重叠**（区间图是完美图，最少着色数 = 最大团大小 = 最大重叠数）。

用扫描线求最大重叠：每场演出产生两个事件 —— 在 $l_i$ 处 $+1$（开始占用），在 $r_i + 2$ 处 $-1$（释放，因为下一场最早 $r_i + 2$ 开始）。同一时刻的事件必须**先处理 $-1$ 再处理 $+1$**，否则"清扫结束紧接着开始"的两场会被误判为冲突。

时刻值域到 $10^9$，不能开数组，必须排序事件（或离散化）。复杂度 $O(n \log n)$。

### 标程

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;

    // 每场演出占用闭区间 [l, r+1]（多出的 1 个时刻用于清扫）
    // 最少舞台数 = 同一时刻最多有多少场演出在占用舞台
    vector<pair<long long, int>> ev;
    ev.reserve(2 * n);
    for (int i = 0; i < n; i++) {
        long long l, r;
        cin >> l >> r;
        ev.push_back({l, +1});      // 开始占用
        ev.push_back({r + 2, -1});  // 释放（下一场最早 r+2 开始）
    }

    // 同一时刻：先释放再占用（结束清扫后紧接着开始的演出可以复用舞台）
    sort(ev.begin(), ev.end(), [](const pair<long long, int> &a,
                                  const pair<long long, int> &b) {
        if (a.first != b.first) return a.first < b.first;
        return a.second < b.second;
    });

    int cur = 0, ans = 0;
    for (const auto &e : ev) {
        cur += e.second;
        ans = max(ans, cur);
    }
    cout << ans << '\n';
    return 0;
}
```

### 典型失分点

- 释放时刻写成 $r + 1$ 而不是 $r + 2$：清扫占用的是 $r+1$ 这一整个时刻，下一场最早 $r+2$。
- 同一时刻的事件顺序搞反，导致"恰好衔接"的两场被算成冲突（样例 2 会挂）。
- 看到 $l, r \le 10^9$ 还开 `cnt[1000000000]` 数组 —— 内存爆掉，必须排序事件或离散化。
- 用"按开始时间排序 + 优先队列"也能过，但要正确维护每个舞台的可用时刻。
- 部分分策略：$n \le 10$ 时可暴力枚举分配方案；值域 $\le 2000$ 时可用数组差分直接求最大重叠（60 分）。

## T4 瞭望塔

**考点**：线性动态规划、滑动窗口最小值（单调队列）
**难度档位**：压轴题　**建议用时**：45–60 分钟

### 思路

"任意连续 $d$ 座至少有一座塔"等价于：**相邻两座塔的距离不超过 $d$，第一座塔的位置 $\le d$，最后一座塔的位置 $\ge n - d + 1$**。

设 $f[i]$ 表示"在第 $i$ 座山峰建塔，且第 $1$ 到 $i$ 座山峰的所有覆盖要求都满足"时的最小花费。第 $i$ 座塔的前一座塔可以在 $[i - d,\ i - 1]$ 中的任意位置 $j$（距离不超过 $d$）；另外引入虚拟起点 $f[0] = 0$，表示"前面不建塔"，它只在 $i \le d$ 时可用（因为第一座塔必须 $\le d$）。

$$f[i] = c_i + \min_{j \in [\max(0,\, i-d),\ i-1]} f[j]$$

窗口随 $i$ 右移，用单调队列维护窗口最小值，$O(n)$ 完成。最后的答案是 $\min_{j \in [n-d+1,\ n]} f[j]$ —— **注意不是 $f[n]$**，因为最后一座塔不一定要建在第 $n$ 座。

复杂度 $O(n)$。所有花费都要用 `long long`（$2\times10^5 \times 10^9 = 2\times10^{14}$）。

### 标程

```cpp
#include <bits/stdc++.h>
using namespace std;

const long long INF = (long long)4e18;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, d;
    if (!(cin >> n >> d)) return 0;
    vector<long long> c(n + 1);
    for (int i = 1; i <= n; i++) cin >> c[i];

    // f[i]: 在第 i 座山峰建塔，且 1..i 的覆盖要求全部满足时的最小花费
    // f[i] = c[i] + min f[j], j ∈ [max(0, i-d), i-1]，其中 f[0] = 0 是虚拟起点
    vector<long long> f(n + 1, INF);
    f[0] = 0;
    deque<int> q;  // 单调队列，维护窗口 [i-d, i-1] 内 f 值最小的下标
    q.push_back(0);

    for (int i = 1; i <= n; i++) {
        while (!q.empty() && q.front() < i - d) q.pop_front();
        f[i] = c[i] + f[q.front()];
        while (!q.empty() && f[q.back()] >= f[i]) q.pop_back();
        q.push_back(i);
    }

    // 最后一座塔必须落在 [n-d+1, n] 中，才能覆盖最后一段
    long long ans = INF;
    for (int j = n - d + 1; j <= n; j++) ans = min(ans, f[j]);
    cout << ans << '\n';
    return 0;
}
```

### 典型失分点

- 直接输出 $f[n]$：最后一座塔只要在 $[n-d+1, n]$ 内即可，样例 1（答案 $2$，塔在 $2$ 和 $4$）就会挂。
- 窗口左端写成 $i - d + 1$：距离不超过 $d$ 意味着前一座可以在 $i-d$。
- 忘记处理 $i \le d$ 时可以从虚拟起点 $f[0]$ 转移（第一座塔不必紧挨开头）。
- 用 `int` 存花费，溢出。
- 部分分策略：$n \le 20$ 时可 $2^n$ 枚举；$n \le 5000$ 时 $O(n d)$ 或直接 $O(n^2)$ 的 DP 能拿 60 分（本套数据的暴力版即 $O(nd)$）。
