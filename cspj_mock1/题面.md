# T1 图书编号

时间限制：1.0 秒　内存限制：256 MB

## 题目描述

学校图书馆新购进了 $n$ 本书，每本书都有一个编号。编号由两部分组成：前面是若干个大写英文字母（表示书分类），后面紧接着若干个阿拉伯数字（表示该类书内的序号），例如 `AB12`、`C7`、`XYZ0007`。

管理员要按下面的规则给这 $n$ 本书重新排序，方便上架：

1. 数字部分所表示的**整数**较小的书排在前面；
2. 数字部分所表示的整数相同时，**字母部分字典序较小**的书排在前面。

请你输出排好序后的编号。

## 输入格式

第一行一个整数 $n$，表示书的本数。

接下来 $n$ 行，每行一个编号字符串，由大写英文字母后接阿拉伯数字组成。

## 输出格式

输出 $n$ 行，每行一个编号，按题目要求的顺序排列。

## 样例输入 1

```
5
AB12
C7
XYZ0007
A12
B3
```

## 样例输出 1

```
B3
C7
XYZ0007
A12
AB12
```

## 样例输入 2

```
1
Z0
```

## 样例输出 2

```
Z0
```

## 样例解释

样例 1 中，五本书的数字部分分别是 $12$、$7$、$7$、$12$、$3$。按整数从小到大是 $3$、$7$、$7$、$12$、$12$。数字部分为 $7$ 的两本，`C` 的字典序小于 `XYZ`，所以 `C7` 在前；数字部分为 $12$ 的两本，`A` 的字典序小于 `AB`，所以 `A12` 在前。注意 `XYZ0007` 虽然有前导零，但它表示的整数是 $7$，不是 $7$ 位数。

## 数据范围

- 对于 $30\%$ 的数据，$n \le 100$。
- 对于 $60\%$ 的数据，$n \le 5000$。
- 对于 $100\%$ 的数据，$1 \le n \le 10^5$，每个编号由 $1$ 到 $5$ 个大写英文字母后接 $1$ 到 $9$ 个阿拉伯数字组成，数字部分所表示的整数不超过 $10^9$。

# T2 浇水

时间限制：1.0 秒　内存限制：256 MB

## 题目描述

花房里有 $n$ 盆花排成一排，编号依次为 $1$ 到 $n$，第 $i$ 盆花现在的高度是 $h_i$ 厘米。

园丁制定了 $m$ 次浇水计划，第 $j$ 次浇水会让编号在 $l_j$ 到 $r_j$ 之间（含两端）的每一盆花都长高 $1$ 厘米。浇水严格按 $j = 1, 2, \dots, m$ 的顺序依次进行。

园丁想知道：**最早在第几次浇水之后**，会出现一盆高度不低于 $X$ 厘米的花？

如果一开始（第 $0$ 次浇水前）就已经有高度不低于 $X$ 厘米的花，答案为 $0$；如果 $m$ 次浇水全部做完后仍然没有，答案为 $-1$。

## 输入格式

第一行三个整数 $n$、$m$、$X$，分别表示花的盆数、浇水次数和高度标准。

第二行 $n$ 个整数 $h_1, h_2, \dots, h_n$，表示每盆花的初始高度。

接下来 $m$ 行，每行两个整数 $l_j$、$r_j$，表示第 $j$ 次浇水的区间。

## 输出格式

输出一个整数，表示最早达到高度标准的浇水次数；若始终无法达到，输出 $-1$。

## 样例输入 1

```
3 4 5
1 2 3
1 1
2 3
1 3
2 2
```

## 样例输出 1

```
3
```

## 样例输入 2

```
1 3 5
7
1 1
1 1
1 1
```

## 样例输出 2

```
0
```

## 样例输入 3

```
2 2 100
1 1
1 2
1 2
```

## 样例输出 3

```
-1
```

## 样例解释

样例 1：初始三盆花高度为 $1, 2, 3$。第 $1$ 次浇水后为 $2, 2, 3$；第 $2$ 次后为 $2, 3, 4$；第 $3$ 次后为 $3, 4, 5$，此时第 $3$ 盆花高度达到 $5$，所以答案是 $3$。

样例 2：初始唯一一盆花高度就是 $7$，已经不低于 $5$，答案为 $0$。

样例 3：两次浇水后高度为 $3, 3$，始终达不到 $100$，答案为 $-1$。

## 数据范围

- 对于 $30\%$ 的数据，$n, m \le 100$。
- 对于 $60\%$ 的数据，$n, m \le 5000$。
- 对于 $100\%$ 的数据，$1 \le n \le 2 \times 10^5$，$1 \le m \le 2 \times 10^5$，$1 \le h_i \le 10^9$，$1 \le X \le 10^9$，$1 \le l_j \le r_j \le n$。

# T3 舞台

时间限制：1.0 秒　内存限制：256 MB

## 题目描述

剧场近期要举办 $n$ 场演出。第 $i$ 场演出从时刻 $l_i$ 开始，到时刻 $r_i$ 结束（开始和结束时刻都算作演出时间），期间需要**独占**一个舞台。

演出结束后，舞台必须空出 $1$ 个时间单位用于清扫。也就是说，如果某场演出在时刻 $r$ 结束，那么这个舞台在时刻 $r + 1$ 不能被其他演出使用，下一场演出最早只能在时刻 $r + 2$ 开始。

所有演出的时间和时长都已确定，不能调整。请问剧场最少需要准备多少个舞台，才能保证这 $n$ 场演出都能按时举办？

## 输入格式

第一行一个整数 $n$，表示演出的场数。

接下来 $n$ 行，每行两个整数 $l_i$、$r_i$，表示第 $i$ 场演出的开始时刻和结束时刻。

## 输出格式

输出一个整数，表示最少需要的舞台数。

## 样例输入 1

```
3
1 3
2 4
5 6
```

## 样例输出 1

```
2
```

## 样例输入 2

```
2
1 1
3 3
```

## 样例输出 2

```
1
```

## 样例输入 3

```
3
1 10
1 10
1 10
```

## 样例输出 3

```
3
```

## 样例解释

样例 1：第 $1$ 场演出在时刻 $3$ 结束，清扫占用时刻 $4$，所以该舞台下一场最早时刻 $5$ 才能用；但第 $3$ 场演出从时刻 $5$ 开始，而第 $2$ 场演出要到时刻 $4$ 才结束、清扫到时刻 $5$，因此第 $2$、$3$ 场不能共用一个舞台，至少需要 $2$ 个。

样例 2：第 $1$ 场在时刻 $1$ 结束，清扫占用时刻 $2$，第 $2$ 场从时刻 $3$ 开始，恰好可以复用同一个舞台。

样例 3：三场演出时间完全相同，只能各用一个舞台。

## 数据范围

- 对于 $30\%$ 的数据，$n \le 10$。
- 对于 $60\%$ 的数据，$n \le 2000$，且 $1 \le l_i \le r_i \le 2000$。
- 对于 $100\%$ 的数据，$1 \le n \le 2 \times 10^5$，$1 \le l_i \le r_i \le 10^9$。

# T4 瞭望塔

时间限制：1.0 秒　内存限制：256 MB

## 题目描述

一条山脉上有 $n$ 座山峰，从左到右编号为 $1$ 到 $n$。在第 $i$ 座山峰上修建一座瞭望塔需要花费 $c_i$ 元。

出于防火安全考虑，要求满足：**任意连续的 $d$ 座山峰中，至少有一座山峰上建有瞭望塔**。换句话说，对于任意满足 $1 \le p \le n - d + 1$ 的 $p$，山峰 $p, p + 1, \dots, p + d - 1$ 中至少有一座建有瞭望塔。

请你计算，满足要求的最小总花费是多少。

## 输入格式

第一行两个整数 $n$、$d$，分别表示山峰总数和要求中的连续长度。

第二行 $n$ 个整数 $c_1, c_2, \dots, c_n$，表示在每座山峰上建塔的花费。

## 输出格式

输出一个整数，表示最小总花费。

## 样例输入 1

```
5 3
3 1 4 1 5
```

## 样例输出 1

```
2
```

## 样例输入 2

```
3 1
2 3 4
```

## 样例输出 2

```
9
```

## 样例输入 3

```
4 4
5 2 8 1
```

## 样例输出 3

```
1
```

## 样例解释

样例 1：在第 $2$ 座和第 $4$ 座山峰上建塔，总花费 $1 + 1 = 2$。此时连续 $3$ 座山峰的三个区间 $[1, 3]$、$[2, 4]$、$[3, 5]$ 中分别有第 $2$、第 $2$（或第 $4$）、第 $4$ 座山峰上的塔，满足要求。

样例 2：$d = 1$ 意味着每一座山峰自身都必须有塔，总花费 $2 + 3 + 4 = 9$。

样例 3：$d = 4 = n$ 意味着所有山峰中至少有一座塔即可，选最便宜的第 $4$ 座，花费 $1$。

## 数据范围

- 对于 $30\%$ 的数据，$n \le 20$。
- 对于 $60\%$ 的数据，$n \le 5000$。
- 对于 $100\%$ 的数据，$1 \le d \le n \le 2 \times 10^5$，$1 \le c_i \le 10^9$。
